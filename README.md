# 📝 Notepad App — C# WinForms
 
> A clean, lightweight text editor built with **C# .NET Windows Forms**, inspired by the simplicity of classic Windows Notepad.
 
---
 
## ✨ Features
 
| Feature | Description |
|---|---|
| 📄 New File | Start a fresh document instantly |
| 📂 Open | Load any `.txt` file from your system |
| 💾 Save | Save your work with one click |
| 💾 Save As | Save to a new location or filename |
| ✂️ Cut / Copy / Paste | Full clipboard support |
| 🗑️ Clear | Wipe the editor clean in one action |
| 🖥️ Simple UI | Clean, distraction-free interface |
 
---
 
## 🛠️ Technologies Used
 
- **Language:** C#
- **Framework:** .NET Framework
- **UI:** Windows Forms (WinForms)
- **IDE:** Visual Studio

## 🚀 Getting Started
 
### Prerequisites
 
Make sure you have the following installed:
 
- [Visual Studio](https://visualstudio.microsoft.com/) (Community or higher)
- .NET Framework (included with Visual Studio)
### Installation
 
1. **Clone the repository:**
```bash
https://github.com/hashim-ali-19/Notepad_windowform-.net-.git
```
 
2. **Open in Visual Studio:**
   - Launch Visual Studio
   - Go to `File → Open → Project/Solution`
   - Select the `.sln` file
3. **Build & Run:**
   - Press `F5` or click **Start** to build and run the app

## ⚙️ How It Works
 
The application provides a simple text editing environment where users can:
 
- **Type and edit** text freely in the main editor area
- **Open** existing `.txt` files from their file system
- **Save** notes back to disk in `.txt` format
- **Perform editing operations** — cut, copy, paste, and clear
All file operations are handled through standard Windows dialog boxes (`OpenFileDialog` / `SaveFileDialog`), giving users a familiar experience.
